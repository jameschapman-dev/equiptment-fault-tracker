# Equipment Fault Tracker

A Python application for recording equipment faults and tracking their resolution.

## Planned features

- Record faults against equipment.
- Assign priorities and owners.
- Track faults from open to resolved.
- Store records in SQLite.
- Validate inputs and test application behaviour.

## Project purpose

Develop practical skills in Python, SQL, testing and Git while building
a tool that supports engineering and maintenance workflows.

This project uses fictional equipment and demonstration data.
